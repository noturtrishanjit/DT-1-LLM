04 / TAKE IT WITH YOU

Clone it. Train it. Make it yours.

The starter kit includes a runnable tiny Transformer, JSONL training loop, CPU inference, evaluation hooks, and a prompt you can edit.

$ python -m venv .venv
$ pip install -r model/requirements.txt
$ python model/train.py --data data/train.jsonl
$ python model/infer.py --checkpoint checkpoints/best.pt
