# DT lll — Complete setup, run, chat, and training guide

This release contains the trained 14.48M-parameter DT lll checkpoint, the website, the local Flask API, the PyTorch training code, sample data, and browser controls.

## What is included

| Area | Files | Purpose |
|---|---|---|
| Model | `model/model.py` | Transformer architecture and byte tokenizer |
| Training | `model/train.py`, `model/generate_curriculum.py` | Train or extend DT lll |
| Inference | `model/infer.py` | CPU and INT8 terminal inference |
| Evaluation | `model/evaluate.py`, `data/curriculum_eval.jsonl` | Held-out smoke checks |
| Checkpoint | `checkpoints/dt-lll-14m.pt` | Saved 14.48M model |
| Website | `website/` | Responsive DT lll interface |
| Live API | `server.py` | Real model chat and browser training endpoints |
| Prompt | `docs/system_prompt.md` | DT lll behavior prompt |

## 1. Install Python

Use **Python 3.11 64-bit**. Python 3.10–3.12 should work.

Check the installation:

```bash
python --version
```

## 2. Create the environment

### Linux/macOS

```bash
cd dt-lll
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -r model/requirements.txt
```

If `python3.11` is not available, use `python3`.

### Windows PowerShell

```powershell
cd dt-lll
py -3.11 -m venv .venv
.venv\\Scripts\\Activate.ps1
python -m pip install --upgrade pip
pip install -r model\\requirements.txt
```

If PowerShell blocks activation, run the shell as the current user and retry:

```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

## 3. Run the model in the terminal

Normal CPU inference:

```bash
python model/infer.py \
  --checkpoint checkpoints/dt-lll-14m.pt \
  --prompt "Solve 7x - 14 = 35 step by step."
```

Windows PowerShell uses the same command with backticks or one line:

```powershell
python model\\infer.py --checkpoint checkpoints\\dt-lll-14m.pt --prompt "What are you?"
```

Lower-memory INT8 inference:

```bash
python model/infer.py \
  --checkpoint checkpoints/dt-lll-14m.pt \
  --prompt "Write a Java loop that prints 1 to 7." \
  --quantize int8
```

## 4. Run the live website and real model API

Start the local server from the project root:

```bash
python server.py
```

Then open:

```text
http://127.0.0.1:8000
```

The website chat now sends requests to `/api/chat` and generates answers using the real checkpoint. It is not a simulation.

The server exposes these local endpoints:

```text
GET  /api/health
GET  /api/status
POST /api/chat
POST /api/train
POST /api/train/stop
```

Keep the server bound to `127.0.0.1`. The training API has no authentication and should not be exposed to the public internet.

## 5. Chat from the browser

1. Start `python server.py` in a terminal.
2. Open `http://127.0.0.1:8000`.
3. Scroll to the playground.
4. Enter a question or select a quick prompt.
5. The request is sent to the local DT lll API.
6. The answer is generated by `checkpoints/dt-lll-14m.pt` on CPU.

If the browser says it cannot reach the server, keep the terminal running and check that the URL is exactly `http://127.0.0.1:8000`.

## 6. Train from the browser

1. Keep `python server.py` running.
2. Open the **Train** section of the website.
3. Enter a target final step higher than the current checkpoint step.
4. Click **Start training**.
5. The browser calls `/api/train`.
6. Training runs as a background PyTorch process on the same computer.
7. The page polls `/api/status` and shows the process, step, loss, and recent logs.
8. Click **Stop** if you need to terminate the training process.

The browser training panel uses `data/curriculum_train.jsonl` and resumes `checkpoints/dt-lll-14m.pt`. A target of `1800` means “train until step 1800,” not “add 1800 steps.” The server rejects targets that are not higher than the checkpoint’s current step.

## 7. Train from the terminal

The current 14M architecture is:

```text
d_model=384
n_heads=6
n_layers=8
d_ff=1536
```

Continue training to step 2000:

```bash
python model/train.py \
  --data data/curriculum_train.jsonl \
  --out checkpoints/dt-lll-14m.pt \
  --resume checkpoints/dt-lll-14m.pt \
  --steps 2000 \
  --batch-size 8 \
  --device cpu \
  --d-model 384 --n-heads 6 --n-layers 8 --d-ff 1536
```

Start a fresh 14M run by omitting `--resume`:

```bash
python model/train.py \
  --data data/curriculum_train.jsonl \
  --out checkpoints/new-14m.pt \
  --steps 2000 --batch-size 8 --device cpu \
  --d-model 384 --n-heads 6 --n-layers 8 --d-ff 1536
```

Generate the included synthetic curriculum again:

```bash
python model/generate_curriculum.py
```

For serious quality, replace the synthetic data with a large, licensed, human-reviewed dataset. More parameters or more steps cannot compensate for tiny or low-quality data.

## 8. Evaluate the model

```bash
python model/evaluate.py \
  --checkpoint checkpoints/dt-lll-14m.pt \
  --data data/curriculum_eval.jsonl
```

For Java quality, save generated code and compile it with a local JDK. For math, test many unseen values and compare exact final answers. The included evaluator is only a smoke test.

## 9. Stop everything

Stop the web server with `Ctrl+C` in its terminal. Stop browser-launched training with the **Stop** button. From another terminal, if needed:

```bash
# Linux/macOS
pkill -f 'python.*server.py' || true
pkill -f 'python.*model/train.py' || true
```

On Windows, close the terminal running the process or use Task Manager.

## 10. Limitations

This is a small local model, not a Claude-class general AI. It has limited factual knowledge, weak arithmetic reliability, short context, and no built-in web access. Verify important answers. Do not use it for medical, legal, financial, security-critical, or production decisions without expert review.
